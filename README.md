# MediAssistAI-powered clinical report summarizer using OCR + LLM.

- Upload PDF/image lab reports
- Extract biomarkers
- Flag abnormal values
- AI summaries
- Chat Q&A
## Tech Stack
Python, Streamlit, OCR, Groq API, LLaMA 3, Pandas
